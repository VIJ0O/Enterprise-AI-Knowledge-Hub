# System Architecture

## Overview
The Enterprise AI Knowledge Hub uses a modern, modular architecture consisting of a frontend web application and a backend API service.

```
┌─────────────────────────────────────────────────────────────────────────┐
│                          Frontend (React + Vite)                        │
├─────────────────────────────────────────────────────────────────────────┤
│  ┌──────────────────┐  ┌──────────────────┐  ┌──────────────────┐     │
│  │  Sidebar         │  │  Chat Interface  │  │  Doc Uploader   │     │
│  └──────────────────┘  └──────────────────┘  └──────────────────┘     │
│  ┌──────────────────────────────────────────────────────────────────┐  │
│  │  UI Components (Framer Motion, Lucide, Tailwind)                 │  │
│  └──────────────────────────────────────────────────────────────────┘  │
└──────────────────────────────────┬──────────────────────────────────────┘
                                   │ HTTP/REST
┌──────────────────────────────────▼──────────────────────────────────────┐
│                      Backend (FastAPI + LangChain)                      │
├─────────────────────────────────────────────────────────────────────────┤
│  ┌──────────────────┐  ┌──────────────────┐  ┌──────────────────┐     │
│  │  Document API    │  │  Chat API        │  │  Session API     │     │
│  └──────────────────┘  └──────────────────┘  └──────────────────┘     │
│  ┌──────────────────────────────────────────────────────────────────┐  │
│  │  LangChain Orchestration                                          │  │
│  ├──────────────────────────────────────────────────────────────────┤  │
│  │  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐              │  │
│  │  │  Loaders    │  │  Splitters  │  │  Embeddings │              │  │
│  │  └─────────────┘  └─────────────┘  └─────────────┘              │  │

└──────────────────────────────────┬──────────────────────────────────────┘
```

## RAG Pipeline Flowchart

```
┌──────────────────────┐
│  User Uploads Doc    │
└──────────┬───────────┘
           │
           ▼
┌─────────────────────────────────┐
│  Document Loading & Extraction  │
│  (PDF/DOCX/TXT/MD/HTML Loaders) │
└──────────┬──────────────────────┘
           │
           ▼
┌─────────────────────────────────┐
│  Text Splitting (Chunking)      │
│  (RecursiveCharacterSplitter)   │
└──────────┬──────────────────────┘
           │
           ▼
┌─────────────────────────────────┐
│  Embedding Generation           │
│  (OpenAIEmbeddings)             │
└──────────┬──────────────────────┘
           │
           ▼
┌─────────────────────────────────┐
│  Storage in ChromaDB            │
└─────────────────────────────────┘

... (Later, when user asks a question) ...

┌──────────────────────┐
│  User Asks Question │
└──────────┬───────────┘
           │
           ▼
┌─────────────────────────────────┐
│  Generate Query Embedding       │
└──────────┬──────────────────────┘
           │
           ▼
┌─────────────────────────────────┐
│  Semantic Search in ChromaDB    │
│  (Retrieve Top K Chunks)        │
└──────────┬──────────────────────┘
           │
           ▼
┌─────────────────────────────────┐
│  Build Context + Prompt         │
└──────────┬──────────────────────┘
           │
           ▼
┌─────────────────────────────────┐
│  Generate Answer with LLM       │
└──────────┬──────────────────────┘
           │
           ▼
┌─────────────────────────────────┐
│  Return Answer + Source Citations│
└─────────────────────────────────┘
```
