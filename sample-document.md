## What is RAG?

Retrieval-Augmented Generation (RAG) is an AI framework that combines information retrieval with text generation. It enhances the capabilities of large language models by grounding them in external knowledge sources.

### Key Benefits of RAG
- Reduces hallucinations by providing real context
- Keeps information up-to-date without retraining
- Provides source citations for transparency
- Works with enterprise knowledge bases

## System Requirements

To use the Enterprise AI Knowledge Hub, you need:
- Node.js 18 or later
- Python 3.9 or later
- An OpenAI API key or Google API key

## Features

Our platform offers:
1. **Document Upload**: Support for PDF, DOCX, TXT, Markdown, and HTML

4. **Source Citations**: See exactly where information comes from
